# Arcade game files

Drop an HTML5 game build here — it needs an `index.html` at the root of this
folder, plus whatever JS/CSS/asset files it depends on (relative paths from
that `index.html` work as normal).

The Arcade tab's Play button opens `index.html` from this folder in its own
window. Nothing is bundled here by default; this file just keeps the folder
around so the packaged app has somewhere to look.

If you're shipping the game with the game's actual name/characters, make sure
you actually have the rights to bundle and distribute those assets — most
well-known endless-runner mobile games are commercial products with their own
trademarks and licensing, not freely redistributable, even in unofficial
HTML5-port form.
